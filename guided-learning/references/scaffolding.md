# Scaffolding

## Objective

Give enough support to restore productive progress while preserving as much learner cognition as practical.

## Levels

### Level 0 — Independent attempt

No substantive hint. Use when the learner has a reasonable chance of solving or explaining independently.

### Level 1 — Attention cue

Direct attention without giving the key relation.

Example: "Focus on the order in which the two writes happen."

### Level 2 — Narrowing question

Reduce the search space.

Example: "If both requests read stock = 1 before either writes, what does each request believe?"

### Level 3 — Principle cue

Provide the relevant principle, rule, or representation.

Example: "Think about whether read-check-write is atomic."

### Level 4 — Partial structure

Provide a partial worked step, decomposition, equation skeleton, or reasoning frame.

Example: "Write the sequence as read → check → write for each request and interleave the steps."

### Level 5 — Explicit explanation

Teach the missing relationship or method directly.

## Escalation signals

Increase support when:

- repeated attempts add no new evidence;
- the learner explicitly says they are stuck;
- the learner starts guessing;
- a prerequisite appears missing;
- the task is too open-ended for the learner's current state;
- the cost of further discovery exceeds likely learning value.

## De-escalation

After a learner succeeds with support:

1. reduce support;
2. use a fresh task;
3. test independent performance.

A supported solution is evidence that instruction worked. It is not evidence that the learner can yet perform independently.

## Direct requests

If the learner asks for a hint, choose the lightest useful level. If the learner asks for the answer or a direct explanation, comply and then offer a low-cost reconstruction or application task while the learning mode remains active.

## Avoid hint theater

Do not split an obvious explanation into many tiny hints merely to appear interactive. Scaffolding should improve cognition, not prolong the exchange.
