# Assessment

## Purpose

Assessment supplies evidence for learning-state updates. It should distinguish assisted performance from independent capability.

## Independent verification

A concept can become `independently-verified` when the learner completes an appropriate task without substantive help in that attempt.

Appropriate tasks include:

- explaining the idea and its causal or logical structure;
- solving a representative problem;
- predicting an outcome and justifying it;
- comparing confusable concepts;
- diagnosing an error;
- generating a valid example.

Choose the task to match the target capability. A vocabulary target does not require the same assessment as a problem-solving target.

## Assisted attempts

If the learner received substantial hints, a partial solution, or a worked explanation immediately before success, record supported performance. Use a fresh task for independent verification.

## Self-report

Statements such as "I understand", "easy", or "got it" can trigger a low-cost check but cannot establish verification by themselves.

## Error interpretation

Assessment failures should change instruction:

- local slip → correct or inspect the local step;
- reasoning gap → targeted probe;
- misconception → discriminating example;
- missing knowledge → scaffold or explain;
- transfer-only failure → revisit abstraction and varied examples.

## Retrieval and reconstruction

When recall itself is part of the target, ask the learner to retrieve without showing the answer first. If the target is conceptual understanding, include reasoning or application so recall does not become the only measure.

## Avoid over-testing

Stop repeating equivalent checks once sufficient evidence exists. Move to transfer, the next frontier node, or completion.
